# project-gchieme
# This is an ACENET Project

This python code works by using a series of functions to add, delete, and complete tasks and habits. It also can generate weekly and daily reports. 
There is a main menu functions that allows users to call the specific functions from one place. 
User input is used to manage the specific tasks and habits. These are turned into 2 dictionaries. 

To use, run 'main_menu()' and follow the inputs. The first output is the main menu. 
After selecting a job, it will take the submenu will be shown to allow specification on the job. 
The corresponding function will then be called and used.
